# AI Tweet Detection Streamlit App

This clean deploy version does not require saved `.joblib` model files. It trains Logistic Regression and Random Forest directly from the dataset when the app starts.

## Files needed

- `streamlit_app.py`
- `requirements.txt`
- `combined_ai_tweet_detection_dataset.csv`
